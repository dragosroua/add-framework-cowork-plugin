## The Problem

AI creates subtle friction by not understanding *where you are* in your thinking:

- **You're exploring** → AI jumps to solutions
- **You're executing** → AI suggests rethinking
- **You need support** → AI provides complete answers

## The Solution: Three Realms

### 🔴 ASSESS (Explore & Capture)
Gather information, dream, evaluate options.
**No commitments here — pure exploration.**

### 🟠 DECIDE (Prioritize & Commit)
Choose what matters most. Make clear yes/no decisions.
**Your decisions create your reality.**

### 🟢 DO (Execute & Complete)
Work on committed tasks. Ship and deliver.
**Finishing creates livelines — new starting points.**

---

## Commands

| Command | Purpose |
|---------|---------|
| `/add-framework:assess` | Enter ASSESS mode |
| `/add-framework:decide` | Enter DECIDE mode |
| `/add-framework:do` | Enter DO mode |
| `/add-framework:status` | Check current flow status |
| `/add-framework:balance` | Diagnose realm balance |
| `/add-framework:add-help` | Show this help |

---

## Key Insight

**Never mix realms.** When assessing, don't decide. When deciding, don't start doing. When doing, don't reassess.

This separation brings calm.

---

## Quick Start

1. Feeling overwhelmed? → `/add-framework:assess`
2. Need to prioritize? → `/add-framework:decide`
3. Ready to work? → `/add-framework:do`
4. Feeling stuck? → `/add-framework:balance`
